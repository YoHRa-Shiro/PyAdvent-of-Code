# PyAdvent-of-Code

My solutions to the [Advent of Code](https://adventofcode.com/) challenges, written in Python.
All years, all days... hopefully..... one day........ 🎄

## Setup

Clone the repository:
```bash
git clone https://github.com/Shiro/PyAdvent-of-Code.git
cd PyAdvent-of-Code
```

Create and activate a virtual environment:
```bash
python3 -m venv .venv
source .venv/bin/activate
```

Install the project in editable mode:
```bash
pip install -e .
```

This adds the repository root to Python's module search path, allowing you to run any solution directly.

For example:
```bash
python3 events/2015/day1/not_quite_lisp.py
```

## About Advent of Code

[Advent of Code](https://adventofcode.com/) is an annual programming challenge featuring a series of small puzzles released daily from December 1st to December 25th. Each puzzle can be solved using any programming language.
